`H2OGridSearch` finds optimal hyperparameter values for any supported H2O algorithm by training and evaluating a model for each combination of values in a defined hyperparameter space. The search returns the best model directly and makes all candidate models available via the underlying grid.

**Supported algorithms**

`H2OGridSearch` can be applied to: `H2OGBM`, `H2OXGBoost`, `H2ODRF`, `H2OGLM`, `H2OGAM`, `H2ODeepLearning`, `H2OKMeans`, `H2OCoxPH`, and `H2OIsolationForest`.

## Search strategies

Sparkling Water supports two strategies for traversing the hyperparameter space:

| Strategy | Behaviour |
|---|---|
| `Cartesian` | (Default) Trains a model for every combination of hyperparameter values. Terminates after the complete space is exhausted. |
| `RandomDiscrete` | Randomly samples combinations from the hyperparameter space. Can be terminated early based on `maxRuntimeSecs`, `maxModels`, `stoppingRounds`, `stoppingTolerance`, or `stoppingMetric`. |

<Tip>
Use `Cartesian` when the hyperparameter space is small and you need an exhaustive evaluation. Use `RandomDiscrete` with a time or model budget when the space is large.
</Tip>

## Example: grid search on H2ODRF

The following example tunes `ntrees` and `mtries` on a DRF classifier.

<CodeGroup>

```scala Scala
import ai.h2o.sparkling._
val hc = H2OContext.getOrCreate()

// Load and prepare data
import org.apache.spark.SparkFiles
spark.sparkContext.addFile(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
val rawSparkDF = spark.read.option("header", "true").option("inferSchema", "true")
  .csv(SparkFiles.get("prostate.csv"))
val sparkDF = rawSparkDF.withColumn("CAPSULE", $"CAPSULE" cast "string")
val Array(trainingDF, testingDF) = sparkDF.randomSplit(Array(0.8, 0.2))

// Define the base algorithm
import ai.h2o.sparkling.ml.algos.H2ODRF
val algo = new H2ODRF().setLabelCol("CAPSULE")

// Define the hyperparameter space
import scala.collection.mutable.HashMap
val hyperSpace: HashMap[String, Array[AnyRef]] = HashMap()
hyperSpace += "ntrees" -> Array(1, 10, 30).map(_.asInstanceOf[AnyRef])
hyperSpace += "mtries" -> Array(-1, 5, 10).map(_.asInstanceOf[AnyRef])

// Build and run the grid search
import ai.h2o.sparkling.ml.algos.H2OGridSearch
val grid = new H2OGridSearch()
  .setHyperParameters(hyperSpace)
  .setAlgo(algo)
  .setStrategy("Cartesian")

val model = grid.fit(trainingDF)

// Inspect the best model
model.getModelDetails()

// Score with the best model
model.transform(testingDF).show(false)
```

```python Python
from pysparkling import *
hc = H2OContext.getOrCreate()

# Load and prepare data
import h2o
frame = h2o.import_file(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
sparkDF = hc.asSparkFrame(frame)
sparkDF = sparkDF.withColumn("CAPSULE", sparkDF.CAPSULE.cast("string"))
[trainingDF, testingDF] = sparkDF.randomSplit([0.8, 0.2])

# Define the base algorithm
from pysparkling.ml import H2ODRF
algo = H2ODRF(labelCol="CAPSULE")

# Define the hyperparameter space
hyperSpace = {"ntrees": [1, 10, 30], "mtries": [-1, 5, 10]}

# Build and run the grid search
from pysparkling.ml import H2OGridSearch
grid = H2OGridSearch(hyperParameters=hyperSpace, algo=algo, strategy="Cartesian")

model = grid.fit(trainingDF)

# Inspect the best model
model.getModelDetails()

# Score with the best model
model.transform(testingDF).show(truncate=False)
```

</CodeGroup>

## RandomDiscrete with early stopping

Add termination criteria to stop the search before the full space is covered:

<CodeGroup>

```scala Scala
import ai.h2o.sparkling.ml.algos.H2OGridSearch
val grid = new H2OGridSearch()
  .setHyperParameters(hyperSpace)
  .setAlgo(algo)
  .setStrategy("RandomDiscrete")
  .setMaxModels(20)
  .setMaxRuntimeSecs(120)
  .setStoppingRounds(3)
  .setStoppingTolerance(0.001)
  .setStoppingMetric("AUC")

val model = grid.fit(trainingDF)
```

```python Python
from pysparkling.ml import H2OGridSearch
grid = H2OGridSearch(
    hyperParameters=hyperSpace,
    algo=algo,
    strategy="RandomDiscrete",
    maxModels=20,
    maxRuntimeSecs=120,
    stoppingRounds=3,
    stoppingTolerance=0.001,
    stoppingMetric="AUC")

model = grid.fit(trainingDF)
```

## Grid search on H2OIsolationForest

Unsupervised algorithms such as `H2OIsolationForest` require a labelled validation frame so the grid can evaluate and rank produced models.

<Note>
The validation label column must contain exactly two string values. The value representing the negative case must be alphabetically smaller than the positive case. For example: `"0"`/`"1"`, `"false"`/`"true"`, `"no"`/`"yes"`.
</Note>

<CodeGroup>

```scala Scala
import org.apache.spark.SparkFiles
spark.sparkContext.addFile(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
spark.sparkContext.addFile(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate_anomaly_validation.csv")
val trainingDF = spark.read.option("header", "true").option("inferSchema", "true")
  .csv(SparkFiles.get("prostate.csv"))
val validationDF = spark.read.option("header", "true").option("inferSchema", "true")
  .csv(SparkFiles.get("prostate_anomaly_validation.csv"))

import ai.h2o.sparkling.ml.algos.H2OIsolationForest
val algorithm = new H2OIsolationForest()
algorithm.setValidationDataFrame(validationDF)
algorithm.setValidationLabelCol("isAnomaly")

import scala.collection.mutable
val hyperParams: mutable.HashMap[String, Array[AnyRef]] = mutable.HashMap()
hyperParams += "ntrees" -> Array(10, 20, 30).map(_.asInstanceOf[AnyRef])
hyperParams += "maxDepth" -> Array(5, 10, 20).map(_.asInstanceOf[AnyRef])

import ai.h2o.sparkling.ml.algos.H2OGridSearch
val grid = new H2OGridSearch()
grid.setAlgo(algorithm)
grid.setHyperParameters(hyperParams)
val model = grid.fit(trainingDF)
```

```python Python
import h2o
trainingFrame = h2o.import_file(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
trainingDF = hc.asSparkFrame(trainingFrame)
validationFrame = h2o.import_file(
  "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate_anomaly_validation.csv")
validationDF = hc.asSparkFrame(validationFrame)

from pysparkling.ml import H2OIsolationForest
algorithm = H2OIsolationForest(validationDataFrame=validationDF, validationLabelCol="isAnomaly")

hyperSpace = {"ntrees": [10, 20, 30], "maxDepth": [5, 10, 20]}

from pysparkling.ml import H2OGridSearch
grid = H2OGridSearch(hyperParameters=hyperSpace, algo=algorithm)
model = grid.fit(trainingDF)
```

</CodeGroup>

## Key parameters

| Parameter | Description |
|---|---|
| `algo` | The configured (but untrained) algorithm instance to tune |
| `hyperParameters` | Map of parameter name → list of candidate values |
| `strategy` | Traversal strategy: `Cartesian` (default) or `RandomDiscrete` |
| `maxModels` | Maximum models to train (RandomDiscrete only) |
| `maxRuntimeSecs` | Wall-clock time budget in seconds (RandomDiscrete only) |
| `stoppingRounds` | Early stopping: rounds without improvement before stopping |
| `stoppingTolerance` | Minimum relative improvement to continue |
| `stoppingMetric` | Metric monitored for early stopping |
| `selectBestModelBy` | Metric used to pick the best model from the grid (default: `AUTO`) |

## Problem type detection

The grid search inherits problem type detection from the underlying algorithm. Pass `H2ODRFClassifier`, `H2OGBMRegressor`, or any other explicit variant as the `algo` to pin the problem type:

<CodeGroup>

```scala Scala
import ai.h2o.sparkling.ml.algos.classification.H2ODRFClassifier
val algo = new H2ODRFClassifier().setLabelCol("CAPSULE")
```

```python Python
from pysparkling.ml import H2ODRFClassifier
algo = H2ODRFClassifier(labelCol="CAPSULE")
```

</CodeGroup>
