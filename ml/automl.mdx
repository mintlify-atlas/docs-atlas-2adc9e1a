`H2OAutoML` automates the search over H2O's algorithm space and their hyperparameters. Given a labelled dataset, it trains and evaluates many models — including GBM, XGBoost, DRF, GLM, Deep Learning, and Stacked Ensembles — then returns the best model according to a metric you specify (or one it selects automatically). All results are available via a ranked leaderboard.

<Info>
Like every other Sparkling Water estimator, `H2OAutoML` implements the Spark ML `Estimator` interface. Call `.fit(df)` to run AutoML and get a `Transformer` back; call `.transform(df)` on the returned model to score.
</Info>

## AutoML workflow

<Steps>
  <Step title="Start an H2O context">
    AutoML requires an H2O cluster running inside Spark. Create the context once per session.

    <CodeGroup>

    ```scala Scala
    import ai.h2o.sparkling._
    val hc = H2OContext.getOrCreate()
    ```

    ```python Python
    from pysparkling import *
    hc = H2OContext.getOrCreate()
    ```

    </CodeGroup>
  </Step>

  <Step title="Load and prepare data">
    Load your dataset and split it into training and testing sets.

    <CodeGroup>

    ```scala Scala
    import org.apache.spark.SparkFiles
    spark.sparkContext.addFile(
      "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
    val rawSparkDF = spark.read.option("header", "true").option("inferSchema", "true")
      .csv(SparkFiles.get("prostate.csv"))
    val sparkDF = rawSparkDF.withColumn("CAPSULE", $"CAPSULE" cast "string")
    val Array(trainingDF, testingDF) = sparkDF.randomSplit(Array(0.8, 0.2))
    ```

    ```python Python
    import h2o
    frame = h2o.import_file(
      "https://raw.githubusercontent.com/h2oai/sparkling-water/master/examples/smalldata/prostate/prostate.csv")
    sparkDF = hc.asSparkFrame(frame)
    sparkDF = sparkDF.withColumn("CAPSULE", sparkDF.CAPSULE.cast("string"))
    [trainingDF, testingDF] = sparkDF.randomSplit([0.8, 0.2])
    ```

    </CodeGroup>
  </Step>

  <Step title="Configure H2OAutoML">
    Create an `H2OAutoML` instance and set at minimum the label column. All other columns (excluding label, fold, weight, and ignored columns) are treated as features.

    <CodeGroup>

    ```scala Scala
    import ai.h2o.sparkling.ml.algos.H2OAutoML
    val automl = new H2OAutoML()
    automl.setLabelCol("CAPSULE")
    automl.setIgnoredCols(Array("ID"))
    ```

    ```python Python
    from pysparkling.ml import H2OAutoML
    automl = H2OAutoML(labelCol="CAPSULE", ignoredCols=["ID"])
    ```

    </CodeGroup>

    To speed up training, exclude specific algorithms or cap the number of models built:

    <CodeGroup>

    ```scala Scala
    automl.setExcludeAlgos(Array("GLM"))
    automl.setMaxModels(10)
    ```

    ```python Python
    automl.setExcludeAlgos(["GLM"])
    automl.setMaxModels(10)
    ```

    </CodeGroup>
  </Step>

  <Step title="Train and retrieve the best model">
    Call `.fit()`. AutoML returns the best model according to `sortMetric`. If you do not set `sortMetric`, it is chosen automatically based on the problem type.

    <CodeGroup>

    ```scala Scala
    automl.setSortMetric("AUC")
    val model = automl.fit(trainingDF)

    // Optional: inspect raw model details
    model.getModelDetails()
    ```

    ```python Python
    automl.setSortMetric("AUC")
    model = automl.fit(trainingDF)

    # Optional: inspect raw model details
    model.getModelDetails()
    ```

    </CodeGroup>
  </Step>

  <Step title="Score with the best model">
    The returned model is a standard Spark `Transformer`.

    <CodeGroup>

    ```scala Scala
    model.transform(testingDF).show(false)
    ```

    ```python Python
    model.transform(testingDF).show(truncate=False)
    ```

    </CodeGroup>
  </Step>

  <Step title="Inspect the leaderboard">
    The leaderboard is a Spark DataFrame listing all models trained during AutoML with their performance metrics.

    <CodeGroup>

    ```scala Scala
    // Default leaderboard (model_id + core metrics)
    val leaderboard = automl.getLeaderboard()
    leaderboard.show(false)

    // Add specific extra columns
    val leaderboardExtra = automl.getLeaderboard("training_time_ms", "predict_time_per_row_ms")
    leaderboardExtra.show(false)

    // Add all available extra columns
    val leaderboardAll = automl.getLeaderboard("ALL")
    leaderboardAll.show(false)
    ```

    ```python Python
    # Default leaderboard (model_id + core metrics)
    leaderboard = automl.getLeaderboard()
    leaderboard.show(truncate=False)

    # Add specific extra columns
    leaderboard_extra = automl.getLeaderboard("training_time_ms", "predict_time_per_row_ms")
    leaderboard_extra.show(truncate=False)

    # Add all available extra columns
    leaderboard_all = automl.getLeaderboard("ALL")
    leaderboard_all.show(truncate=False)
    ```

    </CodeGroup>
  </Step>

  <Step title="Use other leaderboard models">
    All models from the leaderboard can be retrieved and used for scoring individually.

    <CodeGroup>

    ```scala Scala
    val models = automl.getAllModels()
    models.foreach(_.transform(testingDF).show(false))
    ```

    ```python Python
    models = automl.getAllModels()
    for m in models:
        m.transform(testingDF).show(truncate=False)
    ```

    </CodeGroup>
  </Step>
</Steps>

## Key parameters

| Parameter | Description |
|---|---|
| `labelCol` | Target column for prediction |
| `ignoredCols` | Columns to exclude from features |
| `featuresCols` | If set, only these columns are used as features |
| `maxModels` | Maximum number of models to build (0 = unlimited) |
| `maxRuntimeSecs` | Wall-clock time budget in seconds (0 = unlimited) |
| `sortMetric` | Metric used to rank models in the leaderboard |
| `excludeAlgos` | List of algorithm names to skip (e.g., `GLM`, `XGBoost`) |
| `includeAlgos` | Whitelist of algorithm names to include |
| `nfolds` | Number of cross-validation folds (default: 5) |
| `seed` | Random seed for reproducibility |
| `projectName` | Identifier for the AutoML run; required to resume a run |

## Problem type detection

By default, `H2OAutoML` infers the problem type from the label column:

- **String label** → classification
- **Numeric label** → regression

To fix the problem type regardless of column type, use the explicit subclasses:

<CodeGroup>

```scala Scala
import ai.h2o.sparkling.ml.algos.classification.H2OAutoMLClassifier
import ai.h2o.sparkling.ml.algos.regression.H2OAutoMLRegressor
```

```python Python
from pysparkling.ml import H2OAutoMLClassifier, H2OAutoMLRegressor
```

</CodeGroup>

<Warning>
AutoML explores a large hyperparameter space by default. Set `maxModels` or `maxRuntimeSecs` to bound the search when running interactively or under time constraints.
</Warning>
