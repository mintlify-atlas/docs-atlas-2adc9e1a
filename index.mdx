Sparkling Water bridges [H2O-3](https://github.com/h2oai/h2o-3) and [Apache Spark](https://spark.apache.org/), letting you combine Spark's distributed data processing with H2O's industry-leading machine learning algorithms — all within a single cluster. Build end-to-end ML pipelines that leverage Spark SQL for data preparation and H2O for model training, then deploy using lightweight MOJO models.

## Get started in three steps

<Steps>
  <Step title="Install Sparkling Water">
    Add the Sparkling Water dependency for your Spark version via Maven or pip:

    <CodeGroup>
    ```bash pip (PySparkling)
    pip install h2o_pysparkling_3.5
    ```
    ```xml Maven (Scala)
    <dependency>
      <groupId>ai.h2o</groupId>
      <artifactId>sparkling-water-package_2.12</artifactId>
      <version>SW_VERSION</version>
    </dependency>
    ```
    </CodeGroup>
  </Step>
  <Step title="Create an H2OContext">
    Start H2O services on top of your Spark cluster with a single call:

    <CodeGroup>
    ```scala Scala
    import ai.h2o.sparkling._
    val hc = H2OContext.getOrCreate()
    ```
    ```python Python
    from pysparkling import *
    hc = H2OContext.getOrCreate()
    ```
    </CodeGroup>
  </Step>
  <Step title="Train a model">
    Use H2O algorithms as Spark ML estimators in your pipeline:

    <CodeGroup>
    ```scala Scala
    import ai.h2o.sparkling.ml.algos.H2OGBM
    val gbm = new H2OGBM()
      .setLabelCol("label")
      .setFeaturesCols("feature1", "feature2")
    val model = gbm.fit(trainingDF)
    ```
    ```python Python
    from pysparkling.ml import H2OGBM
    gbm = H2OGBM(labelCol="label", featuresCols=["feature1", "feature2"])
    model = gbm.fit(training_df)
    ```
    </CodeGroup>
  </Step>
</Steps>
